# 阶段 1：围猎路线

你已完成探查，用户确认走围猎路线。你是编排者，通过 spawn 多个子 agent 做并行收集，确保"漏一个就失败"级别的信息完备性。

**完成本阶段并获得用户确认之前，不要读取 `converge.md`，不要做任何需求决策。** 这个阶段只收集事实，不下结论。

---

## 工作目录

校准阶段已创建 `sessions/{YYYYMMDD-HHmmss}/`。所有子 agent 的产出写入此目录。编排者通过文件协调 agent 之间的信息传递——只在自己的上下文中持有摘要级信息做流程决策。

## 步骤 1：侦察

Spawn 侦察 agent（读取 `agents/scout.md` 作为指令传入），传入用户的需求描述和探查阶段的发现。

侦察者产出写入工作目录 `terrain-map.md`，回答：
1. 涉及哪些域（模块、系统、概念域）
2. 各域的规模和复杂度
3. 预期之外的跨域关联

**侦察不是收集。** 侦察者只告诉你"哪里有东西值得看"，不深入分析。

读取 `terrain-map.md` 后进入步骤 2。

## 步骤 2：拆解

### 2a. 拆解

将需求拆解为需要分别收集信息的子问题组。用适合需求的方式拆解，选择时说明理由。

### 2b. 三路交叉验证（硬性关卡）

1. **地图 → 拆解**：地形图中的每个域和每条跨域关联，在拆解中都有归属吗？没有归属的是候选盲点
2. **独立推导**：spawn 一个干净上下文的子 agent，仅传入用户的原始需求描述（不传地形图和你的拆解），任务是独立列出"要完整了解这个需求的影响面，应该覆盖哪些方面"。你在同一上下文内无法真正忽略已有信息——必须用干净注意力池的子 agent
3. **取并集**：三份清单（你的拆解、地形图、独立推导）的并集才是最终的子问题空间。对只出现在一份清单中的项，判断是"确实不涉及"还是"被遗漏了"

### 2c. 呈现

将拆解结构和三路交叉结果呈现给用户确认后，进入步骤 3。

## 步骤 3：并行收集

spawn 子 agent 时，读取对应的 `agents/` 下的 prompt 文件作为子 agent 的指令传入。不要将 agent prompt 读入编排者自己的上下文。

### 3a. 规划收集 agent

每个子问题组 spawn **两个**收集 agent——自底向上和自顶向下各一个。两个方向有系统性的互补盲点，放在同一个 agent 里会因注意力锚定而丧失互补性。

子问题分组原则：
- **拆分条件**（两条都满足才拆为独立的一对 agent）：范围足够聚焦、所需信息源与其他子问题重叠少
- **合并信号**：多个子问题共享同一批信息源，合并为一组避免重复

Agent 数 = 子问题组数 N × 2（方向）+ 1（缺口扫描）。N>4 时先审视能否合并。

向用户确认分组方案。

### 3b. 并行 spawn

同时 spawn 所有收集 agent，每个传入：需求描述、该 agent 负责的子问题、工作目录。

- 自底向上 agent 使用 `agents/collector-bottom-up.md`，产出写入 `findings-{组名}-bottom-up.md`
- 自顶向下 agent 使用 `agents/collector-top-down.md`，产出写入 `findings-{组名}-top-down.md`

同一子问题的两个 agent 互不可见，不同子问题的 agent 也互不可见。

### 3c. 合并与去重

所有收集者完成后，读取所有 `findings-*.md` 文件，合并写入 `findings-merged.md`：
- 去重（同一事实被多个 agent 发现）
- 标注来源（哪个 agent 发现的、哪个方向）
- 仅单方向发现的项特别标注——可能是另一方向的盲点

### 3d. 缺口扫描

Spawn 缺口扫描者（`agents/gap-scanner.md`），传入：需求描述、完整的子问题清单、`findings-merged.md` 的路径。

缺口扫描者只看到合并后的发现，不知道发现是怎么来的。产出写入 `gaps.md`。

### 3e. 最终合并

读取 `gaps.md`，将补充发现合并到 `findings-final.md`。

## 步骤 4：呈现收集成果

读取 `findings-final.md`，提炼摘要向用户呈现：

1. **需求影响面**：涉及哪些模块和系统，它们之间怎么交互
2. **关键发现**：对需求决策有影响的事实（按子问题组织，标注来源）
3. **待收敛的问题**：需要在下一阶段与用户讨论确认的决策点

用户确认后，读取 `converge.md` 进入收敛阶段。
